# Принятые решения

## Этап 1

- Родителя на этапе 1 создаёт admin вручную в админке.
  Приглашение по одноразовой ссылке - на этапе 6 вместе с кабинетами.
- Создавать учеников на этапе 1 может только admin.
  Преподаватель получит это право вместе с группами на этапе 6.
- Папку notifier/ не создаём до этапа 7.
- Ограничение попыток входа (защита от подбора пароля) - на этапе 8.
- Пароли хэшируются argon2id (@node-rs/argon2).
- Сессии Auth.js хранятся в JWT-cookie (с входом по паролю Auth.js
  не умеет хранить сессии в базе). Поэтому при каждом запросе
  пользователь заново читается из базы: заблокированный аккаунт
  теряет доступ сразу, а смена роли действует без перелогина.
- Пакеты web/ ставятся через npm, без workspaces: сервисы на разных языках
  и между собой код не делят.
